# True Final Ascent – bug reports, ideas and releases

This is the public tracker for **True Final Ascent**, a mod for [PEAK](https://store.steampowered.com/app/3527290/PEAK/).
The mod's source code is not public; this repository only holds issues, discussions and release notes.

- **Download:** [Thunderstore](https://thunderstore.io/c/peak/p/CptPICHU/TrueFinalAscent/) (the only official source)
- **Website:** [tfa.pichuclub.de](https://tfa.pichuclub.de) – daily map times, the Apocalypse chronicle, news and the modding docs
- **Releases:** [GitHub releases](https://github.com/CptPICHU/TrueFinalAscent-Issues/releases) with the changelog of each version

## Reporting a bug

[Open a bug report](https://github.com/CptPICHU/TrueFinalAscent-Issues/issues/new?template=bug_report.yml) and fill in
the form. Logs help most: open the pause menu, pick the session in the list under **BUG REPORT** (bottom right) and
click the export icon next to the list. Attach the zip from the mod's Saved folder to the report.

Please search the [open issues](https://github.com/CptPICHU/TrueFinalAscent-Issues/issues) first; a 👍 on an existing
report helps more than a duplicate.

## Ideas and questions

Ideas for weathers, modes, biomes or badges go into a
[feature request](https://github.com/CptPICHU/TrueFinalAscent-Issues/issues/new?template=feature_request.yml).
Questions and open discussions go to [Discussions](https://github.com/CptPICHU/TrueFinalAscent-Issues/discussions).

## Status labels

| Label | Meaning |
| --- | --- |
| `needs info` | More details or a log zip are needed |
| `confirmed` | Reproduced, will be fixed |
| `in progress` | Being worked on |
| `in test build` | Fixed in a test build, waiting for the release |
| `released` | Fixed in the version of the issue's milestone |
